4BSAMONTE GitHub Pages conversion
=================================
Open index.html locally or publish this folder to a GitHub repository and enable GitHub Pages.

Important limitation:
PHP and MySQL cannot run on GitHub Pages. This version replaces PHP pages with a browser-based HTML/CSS/JavaScript demo. Records are stored in the visitor's browser localStorage and are not shared between users/devices. Login is demo-only and is NOT secure authentication. Do not use real passwords or sensitive student data.

Demo logins:
Admin: admin / admin12345
Registrar: registrar / reg12345
Dean: dean / dean12345
Instructor: instructor / teach12345
Student: student / stud12345

The images and original style.css are included. Initial sample data is created automatically in the browser. Use the browser's local storage reset/clear to reset the demo data.
